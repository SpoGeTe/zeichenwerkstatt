# Zeichenwerkstatt

Technisches Zeichnen spielerisch üben – 9 Stationen für das iPad (Apple Pencil oder Finger).

1. Skizze oder Technische Zeichnung? – Karten sortieren
2. Die Maßangaben – Fachbegriffe an die Zeichnung ziehen
3. Linienarten zeichnen – mit Lineal-Werkzeug, automatische Prüfung
4. Linien im Schaubild – Bezeichnung und Verwendung zuordnen
5. Doppelt so groß – Werkstück auf Kästchen vergrößern
6. Der Maßstab – Quiz und drei Zeichenaufgaben
7. Die Maßpfeile – 12 Pfeile zeichnen und ausmalen
8. Die Normschrift – nachspuren und selbst schreiben
9. Messen und Bemaßen – virtuelles Lineal und Bemaßung nach Regeln

Alle Stationen prüfen die Lösung selbst und geben eine inhaltliche Rückmeldung.
Der Fortschritt wird nur lokal auf dem Gerät gespeichert (keine Anmeldung, keine Daten auf einem Server).

**Tipp fürs iPad:** In Safari „Teilen → Zum Home-Bildschirm“ – dann startet die Zeichenwerkstatt wie eine App im Vollbild.

Reine HTML/CSS/JavaScript-Seite ohne Build-Schritt – läuft direkt über GitHub Pages.
